# Research Reports

Every member submits **one research report** covering assigned topics, recommended technologies, required tools, proposed solutions and possible technical challenges.

## Files

| Member | File | Focus |
|---|---|---|
| 1 | `skeldo265-architecture.md` | Architecture, API, auth, AI API integration |
| 2 | `lau-frontend-backend.md` | React, Tailwind, forms, farm management |
| 3 | `linna-ai-ml.md` | LLMs, crop advice, datasets for Malawi |
| 4 | `frost289-computer-vision.md` | Image analysis, YOLO, SAM, voice, Chichewa |
| 5 | `irvin-design-docs.md` | UI/UX, branding, smallholder farmer needs |

Start from `TEMPLATE.md`. Keep one file per member, written in Markdown.

## Rules

- Cite sources (links, papers, docs) for every claim and number.
- Recommend one option clearly, and explain why others were rejected.
- Be specific to Malawi smallholder farmers where relevant.
- Submit through a pull request to `develop` (branch `docs/research-<member>`).
